## Project Overview

PowerShell-based Microsoft 365 compliance audit system. Connects to multiple customer tenants via GDAP (Granular Delegated Admin Privileges) and runs Maester/Pester test suites to validate security configurations. Results are saved as JSON per tenant, then exported to Excel and HTML reports uploaded to SharePoint.

## Prerequisites & Module Installation

```powershell
Install-Module -Name Microsoft.Graph
Install-Module -Name Microsoft.Graph.Beta
Install-Module -Name ExchangeOnlineManagement
Install-Module -Name Pester
Install-Module -Name Maester
Install-Module -Name ImportExcel
```

## Entry-Point Scripts

Each script is independently callable from Task Scheduler:

| Script | Purpose |
|--------|---------|
| `Invoke-UpdateTeamMapping.ps1` | Download team→tenant mapping from URL → save as `team-mapping.json` |
| `Invoke-Audit.ps1` | Run full audit of all tenants → save JSON results |
| `Invoke-ReportExcel.ps1` | Export failure report to Excel (.xlsx) from saved results |
| `Invoke-ReportHtml.ps1` | Generate HTML report per tenant + merged `_summary.html` |
| `Invoke-SharePointUpload.ps1` | Upload HTML + Excel reports to SharePoint |
| `Send-DailySummary.ps1` | Send daily summary email (MS Graph Send-Mail) |
| `Invoke-CleanupOldReports.ps1` | Delete JSON result files older than `ResultsRetentionDays` (date parsed from filename) |
| `Invoke-All.ps1` | Run all operations in sequence |

## Running Tests (Maester interactive)

```powershell
Connect-Maester          # Authenticate interactively
Invoke-Maester           # Run all tests
Invoke-Maester -Tag PATRON  # Run only PATRON-IT custom tests
```

## Updating Maester & Community Tests

```powershell
Update-Module Maester -Force
Import-Module Maester
Update-MaesterTests
```

## Architecture

### Key Files

| File | Role |
|------|------|
| `Config.ps1` | Runtime config: cert thumbprint, tenant IDs, app ID, result dirs, email, team mapping paths — **gitignored, env-specific** |
| `Config.example.ps1` | Configuration template |
| `Bootstrap.ps1` | Dot-sources all shared functions and config — used by every entry-point script |
| `ConfigTestSuite.ps1` | Which Maester test tags to run — **committed, shared across all environments** |
| `team-mapping.json` | Cached TenantId→Team mapping (generated by `Invoke-UpdateTeamMapping.ps1`) — **gitignored** |
| `Functions/Types.ps1` | PowerShell class definitions (`ConnectionConfig`) |
| `Functions/Audit.ps1` | `Invoke-TenantAudit` + connection helpers + Team field injection into result JSON |
| `Functions/Customers.ps1` | `Get-GdapCustomers` — lists active GDAP delegated admin relationships |
| `Functions/Results.ps1` | `Get-TestsResultsFailed`, `Get-TestsResultsChanged`, `Export-FailureReport` |
| `Functions/Email.ps1` | `Send-DailySummaryEmail` stub (MS Graph Send-Mail, not yet implemented) |

### Test Suites

**`Tests-PATRON/`** — Custom PATRON-IT tests (always maintained here):
- CA policy baselines compared against JSON templates in `Tests-PATRON/CAPTemplates/`
- Authentication method policies (FIDO2, Authenticator, TAP)
- Exchange anti-spam, DKIM/DMARC, audit log, legacy MFA, MFA registration
- Entra device settings, external collaboration, directory sync

**`Tests-Maester/`** — Standard compliance frameworks (auto-updated by `Update-MaesterTests`):
- `CIS/` — CIS Microsoft 365 Foundations Benchmark
- `CISA/` — US CISA SCuBA guidelines
- `EIDSCA/` — Entra ID Security Config Analyzer
- `ORCA/` — Exchange Online protection analyzer
- `Custom/` — Tenant-specific overrides
- `maester-config.json` — Severity overrides for 1400+ community tests

### Data Flow

```
Invoke-UpdateTeamMapping.ps1 → team-mapping.json
                                      │
Config.ps1 + ConfigTestSuite.ps1 → Invoke-Audit.ps1
  └─ Invoke-TenantAudit (Functions/Audit.ps1)
       ├─ Authenticate (certificate) to home tenant
       ├─ List GDAP customers (Graph API)
       └─ For each customer:
            ├─ Connect-MgGraph (delegated)
            ├─ Connect-ExchangeOnline (delegated)
            ├─ Invoke-Maester -Tag <tags from ConfigTestSuite.ps1>
            ├─ Save → ResultsDirectory/{tenantId}/Test-Results-{timestamp}.json
            └─ Inject Team field from team-mapping.json into result JSON

Invoke-ReportExcel.ps1  → ResultsDirectoryReport/_summary.xlsx
Invoke-ReportHtml.ps1   → ResultsDirectoryReport/{TenantName}.html + _summary.html
Invoke-SharePointUpload.ps1 → SharePoint (HTML + xlsx)
```

### Test Result JSON Schema

```json
{
  "Result": "Failed|Passed",
  "FailedCount": N, "PassedCount": N, "SkippedCount": N, "NotRunCount": N,
  "TenantId": "UUID", "TenantName": "string", "Team": "string",
  "LoadedModules": [...], "PowerShellInfo": {...}
}
```
